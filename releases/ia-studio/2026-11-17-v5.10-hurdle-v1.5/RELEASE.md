# iA Studio v5.10 / Hurdle Calculator v1.5 — Single Tile
Date: 2026-11-17
Status: Preview only; public portfolio unchanged until explicit approval.

## Changes
- Entire Advanced Settings · Game & Casino Economics section removed, including all its explanatory text and fields.
- Main Target Bet → Suggested Promo tile is the only input/output panel.
- Game category and specific game now appear in the main tile to preserve Table Games and Slots support.
- Four qualifying hours/day and one playing day remain editable in the main tile.
- Slot play-speed and hold inputs appear only for Slots; no fabricated slot defaults.
- Optional actual casino win/loss field moved into the main profitability area, so estimated versus actual contribution remains available.
- All 13 existing table-game historical rating assumptions preserved.
- Economic model now explicitly fixes assumptions at illustrative 30% Theo reinvestment, 100% promotional economic cost, zero additional trip expenses or commissions. These are hypothetical assumptions, NOT approved casino policy; suggestions should not be presented as verified property offers.
- Default suggestion rounded down in $50 steps; approximately 62.5% upfront and the remainder after verified qualifying play.
- Copy and Print functions preserved.
- This public-facing model cannot establish property-specific profit; both theoretical and actual gaming contribution exclude unmodeled operating/trip expenses.
